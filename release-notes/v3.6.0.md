# Toolbox v3.6.0

## What's new

- **The blue theme is back in dark mode.** Blue-tinted surfaces and a blue primary, as before the Conductor restyle. Light mode keeps the Conductor paper neutrals and gains blue highlights: the primary button, focus ring and section accents.
- **The mod market page uses the same palette.**

## Fixed

- On Windows the app no longer waits 30 seconds and fails with "Server did not become ready" when another program already listens on the port. It now picks a free port instead.

## Install

Download from [GitHub Releases](https://github.com/MerlijndeVos/Toolbox/releases/tag/v3.6.0):

| Platform | File |
|----------|------|
| Windows | `Toolbox-Setup-3.6.0-win64.exe` |
| macOS | `Toolbox-3.6.0-macos.dmg` |
| Linux | `Toolbox-3.6.0-linux-{arch}.AppImage` |

Installers are **unsigned**. Windows SmartScreen and macOS Gatekeeper may ask you to confirm once (“Run anyway” / “Open”).

**ffmpeg** is not bundled in the installer. On first launch the app downloads a one-time essentials build into your user data folder.
