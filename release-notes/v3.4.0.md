# Toolbox v3.4.0

## What's new

- **Subtitle translation is far more reliable.** Cues the model skips, garbles or returns with broken tags or line breaks are asked for again, then one at a time, instead of silently keeping the source text. A failing file no longer stops the rest of a folder, output is written atomically, and finished batches are checkpointed so a retry resumes instead of paying again. **Cancel now really stops** the run and writes nothing. Files in Windows-1252 or UTF-16 are decoded properly instead of filled with replacement characters.
- **Better translations.** Formatting tags (`<i>`, `{\an8}`, ASS overrides) are protected, each cue carries a reading-speed budget, the model sees more context (8 earlier cues and 3 upcoming ones), and ads and credit lines are dropped before translating. A **glossary** and **notes about the show** keep names and terms consistent. With no language tag in the filename, the model detects the source language. A folder run skips files already in the target language.
- **WebVTT and ASS/SSA.** Translate reads and writes `.vtt`, `.ass` and `.ssa` as well as SRT, keeping styles, positions, notes and non-dialogue lines.
- **Faster, and optionally sharper.** Run up to 4 batches at once, add a **review pass** that fixes mistranslations (about twice the tokens), or pick a model per run. Preview now shows an estimate of the requests and tokens a translation will use.
- **Use your Claude subscription.** A new **Claude subscription** AI provider runs the Claude Code program on your computer with your Pro or Max plan, so no API key is needed. An optional `claude setup-token` token is supported.
- **Usage window.** **Settings → AI** shows the tokens used per day, task and model, recent calls, and your Claude plan's 5-hour and weekly limits with reset times.

## Fixed

- A title word at the end of a subtitle name (`Where.Is.It.srt`) is no longer read as a language tag, so Rename and Translate keep the full title.
- OpenAI models that reject a custom temperature are retried without it.

## Install

Download from [GitHub Releases](https://github.com/MerlijndeVos/Toolbox/releases/tag/v3.4.0):

| Platform | File |
|----------|------|
| Windows | `Toolbox-Setup-3.4.0-win64.exe` |
| macOS | `Toolbox-3.4.0-macos.dmg` |
| Linux | `Toolbox-3.4.0-linux-{arch}.AppImage` |

Installers are **unsigned**. Windows SmartScreen and macOS Gatekeeper may ask you to confirm once (“Run anyway” / “Open”).

**ffmpeg** is not bundled in the installer. On first launch the app downloads a one-time essentials build into your user data folder.

## Updating from v3.3.1

Use **Settings → Updates → Update to v3.4.0** in the desktop app, or download the new installer for your OS from the table above.
