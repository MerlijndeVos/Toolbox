# Toolbox v3.5.0

## What's new

- **A new look, based on the Conductor design system.** Warm paper neutrals, an ink primary button, flat panels with a ruled header, and Geist and Geist Mono (bundled with the app). Colour is kept for states and money.
- **New layout.** A fixed sidebar and a top bar with the page title replace the old header. Home lists each category as a panel of tools and shows your recent runs, with an **Undo rename** button.
- **Neutral default theme.** The default palette, font stack and category accents are neutral. Installed themes keep working, and themes can set a new `chrome` token for the sidebar, header and log.

## Changed

- Releases are cut from the `production` branch only. The release workflow refuses a version tag or manual run whose commit is not on it.

## Install

Download from [GitHub Releases](https://github.com/MerlijndeVos/Toolbox/releases/tag/v3.5.0):

| Platform | File |
|----------|------|
| Windows | `Toolbox-Setup-3.5.0-win64.exe` |
| macOS | `Toolbox-3.5.0-macos.dmg` |
| Linux | `Toolbox-3.5.0-linux-{arch}.AppImage` |

Installers are **unsigned**. Windows SmartScreen and macOS Gatekeeper may ask you to confirm once (“Run anyway” / “Open”).

**ffmpeg** is not bundled in the installer. On first launch the app downloads a one-time essentials build into your user data folder.
